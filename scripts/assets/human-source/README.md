# Human graphical assets

Fictional character geometry, rig, morph targets, hair, clothes and textures from MakeHuman Community. These graphical assets are CC0; see LICENSE.md. No MakeHuman application code is included.

Sources:
- https://github.com/makehumancommunity/makehuman/tree/master/makehuman/data
- https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html
- https://files.makehumancommunity.org/asset_packs/makehuman_system_assets/makehuman_system_assets_cc0.zip

Rebuild with Blender Python 4.2. The base room file is generated by build-choices.py followed by build-wall-rooms.py. Then run build-human-cast.py, export-human-rooms.py, and optimize-human-textures.mjs with a toolchain containing glTF Transform 4.2.1, draco3dgltf and sharp. Render preview with render-human-rooms.py --preview-only. Render each room in a separate process using --no-preview --room=N and encode-human-motion.py N (ffmpeg). Do not run the legacy static optimizer on skinned actors.

All fourteen fictional characters have separate skinned animation clips. The web viewer uses these clips through AnimationMixer; browsers without WebGL use short muted loops rendered from the same scene and camera. Reduced motion and the pause control stop playback. Dialogue is authored separately in app/story-dialogue.ts and is illustrative, not a quotation from real people.
