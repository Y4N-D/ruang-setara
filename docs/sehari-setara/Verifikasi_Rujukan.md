# Verifikasi rujukan — Sehari Setara

Daftar ini mencatat apakah setiap rujukan pasal yang tampil di kartu dampak sudah dicocokkan dengan naskah resmi di JDIH. Permainan baru boleh ditautkan dari galeri (F-11) setelah semua kotak tercentang.

## Cara memakai

1. Cocokkan rujukan dengan naskah resmi di JDIH.
2. Bila sesuai, ubah `[ ]` menjadi `[x]`, lalu isi sumber serta nama dan tanggal pemeriksaan.
3. Bila tidak sesuai, jangan dicentang. Tulis temuan di baris "Catatan", lalu sampaikan kepada agen. Perubahan rujukan memerlukan keputusan pemilik proyek.

Lewat situs GitHub: buka file ini, klik ikon pensil (Edit), ubah kotaknya, lalu klik "Commit changes".

Jaga baris pertama setiap butir tetap utuh: kotak, kode R-xx, dan teks rujukan. Pemeriksa konten (`content:check`) hanya membaca baris itu; baris lain bebas diisi. Mengubah file ini tidak pernah membuat situs gagal terbit. Baris yang rusak hanya membuat rujukannya dianggap belum terverifikasi.

## Aturan untuk agen

Agen dilarang mencentang kotak. Rujukan baru ditambahkan dengan kotak kosong. Bila teks sebuah rujukan berubah, agen mengosongkan kotaknya agar diverifikasi ulang (`AGENTS.md` bagian 8).
